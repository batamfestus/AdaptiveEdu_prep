topic: Measurements and Units

## Convert and use SI units
The base SI units are metre (m), kilogram (kg), second (s), ampere (A), kelvin (K), mole (mol) and candela (cd). Derived units are built from them: newton $N = kg\,m/s^2$, joule $J = N\,m$, watt $W = J/s$, pascal $Pa = N/m^2$, hertz $Hz = 1/s$.

Prefixes: kilo $10^3$, mega $10^6$, centi $10^{-2}$, milli $10^{-3}$, micro $10^{-6}$, nano $10^{-9}$.

Worked example: $72\ km/h = 72 \times 1000 / 3600 = 20\ m/s$.

Common mistakes: forgetting to convert grams to kilograms or km/h to m/s before using a formula. Both sides of an equation must have the same units.

## Handle errors and significant figures
Accuracy is how close a measurement is to the true value. Precision is how close repeated readings are to each other. A systematic error (for example a zero error) shifts every reading the same way. A random error scatters the readings.

Significant figures are counted from the first non-zero digit. When multiplying or dividing, the answer has as many significant figures as the least precise value.

Percentage error = (absolute error / measured value) $\times$ 100. Worked example: an error of 0.5 cm on 20 cm is 2.5%.

Common mistakes: mixing up accuracy and precision, and quoting more digits than the data support.
