# Study notes (the AI tutor's knowledge base)

The AI tutor answers ONLY from these notes plus each question's own explanation, so their
quality sets the quality of the tutor.

**These starter notes were drafted by Claude. They are NOT verified.** Read every note against
your own teaching material and the official JAMB syllabus, correct anything wrong, and rewrite
them in your own words. Your review is what makes the tutor trustworthy.

## Format
- One file per topic. The first line is `topic: <exact syllabus topic name>`.
- Each `## Heading` is one competency and must match the syllabus competency name exactly.
- Keep each section short and focused: definition, formulas, one worked example, common mistakes.
- Write formulas between dollar signs, like `$v = u + at$`.
- The Admin page shows how much of the syllabus the notes cover.
